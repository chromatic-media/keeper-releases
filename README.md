# Keeper releases

Keeper turns a spare computer into a home NAS (network storage) that is simple to look after.

This page lists Keeper's releases. Each release has plain notes on what changed and how to update.
A Keeper box looks here once a day (only when it has internet) and tells its owner when a new version
is out. It never installs anything by itself.

**How to update a Keeper box:** download the new install stick from the release, write it to a USB
stick, start the box from it, and pick **Bring back my files**. Your files, folders, Windows shares,
snapshots and backups stay as they are.

Keeper's source code is kept private for now; only the release notes and install sticks are shared here.
